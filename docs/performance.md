# 性能优化与验证

2026-10-09，性能优化代码迁入原始源码仓库 `D:\Work\repository\black-desert-workerman` 的 `codex/vue-performance` 分支。

## 改动

- 游戏 JSON 与 WASM 并行加载；静态数据跳过深层响应式处理。
- 语言文件在构建时从原 `loc.json` 拆分，只加载当前语言。
- 路由、首页地图与首次打开的弹窗按需加载；弹窗关闭后保留已有状态。
- 候选城镇路径与收益计算分离；价格变化复用路径，节点图或城镇条件变化则重新寻路。
- 工人平均属性缓存；距离列表预建索引。
- 地区地图只加载当前图层，切换后复用下载数据。三个地图页面均取消未完成请求并调用 `Deck.finalize()`。
- 三个地图页面的背景瓦片均改为本地 `data/maptiles/`，开发服务直接读取，生产构建复制到 `dist/data/maptiles/`。
- 集中保存用户和地图状态，合并连续更新并在页面退出时同步保存；统计页面卸载时移除主题监听器。

## 本地测量

Chromium，1440 × 900，固定行情测试数据。JSON 与 WASM 请求统一增加 80 ms 延迟；时间结果用于同机对比，不能作为线上加载时间承诺。资源大小均为未压缩大小。

| 指标 | 原构建 | 优化后 |
|---|---:|---:|
| 首页实际加载的 JS（含地图） | 2,318,711 B | 939,582 B |
| 直接进入采集点页面加载的 JS | 2,318,711 B | 212,377 B |
| 游戏数据初始化 | 2,327 ms | 458 ms |
| 采集点页面数据就绪与列表显示 | 4,716 ms | 1,446 ms |
| 修改税率的刷新中位数，5 次 | 795 ms | 146 ms |
| 每次修改税率的寻路次数 | 370 | 0 |
| 英语语言数据 | 2,758,992 B，包含全部语言 | 270,665 B |
| 默认地区图层数据 | 20,888,747 B，两种图层 | 5,705,992 B，仅 RG |

## 验证

- `npm test`：31 项通过，包含并行加载、失败响应、距离索引、缓存失效和退出保存检查。
- `npm run build`：输出到本仓库的 `dist/`，生成语言片段并复制运行所需的数据与图标；原始 `data/` 保留。
- 比较 370 个采集点在初始税率及 5 个修改值下的全部收益、成本、推荐城镇与工人；结果与原构建逐项一致。启用 Ancado 后再次对比一致，WASM 路径结果一致。
- 浏览器遍历全部 13 个路由；切换语言、切换两种地区图层、首次打开弹窗、退出地图及加载中退出均通过，没有运行时错误。
- 源码恢复后同步修复上游旧页面首次选择失效、旧城镇页面调用已移除方法，以及路由测试重新初始化集合的错误。统计模型的旧测试断言更新为当前已部署预设。
