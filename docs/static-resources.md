# 静态资源加载与 Vercel 缓存

2026-10-09。本次针对静态资源下载量、请求数和重复访问的网络开销调整。

## 资源发布

- 生产环境将游戏 JSON 合并为 `game-core.json` 和 `game-planner.json`，分别用于采集点基础计算及住宿、仓库、工作坊规划。开发环境继续读取原始 JSON。
- 所有运行时 JSON 和 GeoJSON 在输出时去除空白，源文件保持原样。
- JSON 使用文件内容的 SHA-256 前 16 位作为 URL 目录；图标、地图瓦片和说明图片使用各自目录的内容哈希。相同资源在重复构建时使用相同 URL。
- 发布文件由运行时清单决定；历史观测 JSON、完整语言源文件、未使用的距离文件及整图 `whole.webp` 不进入输出。原始资料仍保留在 `data/`。
- `npm run build` 清理 `dist/data/` 中上一次构建的输出，再写入当前版本，避免历史文件累积。

## 瓦片图片压缩（2026-10-10）

生产构建对瓦片生成 WebP 压缩候选，默认最大尺寸为 192×192、质量为 60、编码 effort 为 6。缩放保留完整图片和宽高比，不裁剪，不放大较小的原图；透明通道保留。每张候选只有严格小于原文件时才进入发布目录，否则使用原文件的全部字节。

原始 `data/maptiles/{z}/{x}_{y}.webp` 始终作为构建输入。压缩结果保持层级、坐标文件名和地理边界；地图组件的 `tileSize`、`extent`、`zoomOffset`、图标图层和连线图层保持原值。降低像素尺寸会使放大后的底图细节变柔和。

压缩使用固定版本的 Sharp，仅属于构建依赖。缓存位于 `.cache/maptiles/`，按原图内容、压缩参数及 Sharp/libvips/WebP 版本生成键。参数、原图或编码器发生变化时重新处理；无变化时复用缓存。缓存使用临时文件和原子替换写入，不完整的缓存会从原图重新生成。构建会显示处理进度，并汇总原始字节、发布字节、采用压缩版与保留原版的图片数量。

开发服务继续使用原图；生产预览使用构建输出。缓存目录及 `dist/` 不纳入版本控制。

2026-10-10 完整构建实测：18,334 张瓦片从 105,608,806 B 降为 29,703,550 B，减少 71.9%。本次全部候选均比原图更小；较小原图不获益时保留原始字节的分支由测试覆盖。发布数据目录总大小从 143,044,176 B 降为 67,138,920 B。

## 缓存与部署

`vercel.json` 对 `/assets/` 和 `/data/<16 位内容哈希>/` 的资源及其 `/workerman/` 路径设置：

```http
Cache-Control: public, max-age=31536000, immutable
```

页面入口沿用 Vercel 的重新校验行为。发布新版本时，HTML 引用新的 JS，JS 中的资源清单引用新的数据 URL；未修改的资源继续使用原 URL。

Vercel [自动协商传输压缩](https://vercel.com/docs/how-vercel-cdn-works/compression)，无需另发 `.gz` 或 `.br` 文件。上线后检查实际响应的 `Content-Encoding`、`Content-Type`、`Cache-Control`，以及浏览器 Network 中的传输大小。本地 Vite preview 的缓存头与 Vercel 不同。

配置独立资源 CDN 时，在 Vercel 的构建环境中设置 `VITE_ASSET_BASE_URL`。该地址包含资源部署前缀，例如 `https://assets.example.com/workerman/`；同步完整的 `dist/data/` 并设置 CORS。仅配置环境变量不会自动上传资源。

## 本地测量

大小为十进制字节；Brotli 使用质量 9，Gzip 使用级别 6。本地压缩结果用于估算，Vercel 实际压缩参数可能不同。

| 指标 | 原始值 | 调整后 |
|---|---:|---:|
| 无工人的采集点页游戏 JSON，不含语言 | 5,212,912 B，21 个请求 | 1,502,601 B，1 个请求 |
| 首页游戏 JSON，不含语言 | 5,212,912 B，21 个请求 | 4,007,886 B，2 个请求 |
| 基础包 Gzip / Brotli | — | 209,097 B / 169,991 B |
| 规划包 Gzip / Brotli | — | 243,300 B / 186,807 B |
| 发布数据目录总大小（2026-10-09，尚未重新压缩瓦片） | 168,215,921 B | 143,044,176 B |
| 默认首页 WASM 请求 | 631,434 B | 启用 WASM 时才请求；当前 v0.4.0 文件为 689,058 B |

发布目录总大小包含按视区加载的地图瓦片，不代表一次页面访问的下载量。首屏改善主要来自按页面加载、传输压缩和浏览器缓存。
